FaceitEsportDiag

Collecteur Windows read-only pour un diag CS2 / FACEIT : hardware, Secure Boot / TPM / VBS, moniteur, NIC latency props, GPU, Steam/CS2 cfg, WHEA. Pas de tweak automatique.

Télécharger le .ps1

01 — Lancer (Admin)

  1. Télécharge FaceitEsportDiag.ps1 (dossier Téléchargements).
  2. Clic droit sur PowerShell → Exécuter en tant qu’administrateur.
  3. Colle puis Entrée :

Set-ExecutionPolicy -Scope Process Bypass -Force;
cd $env:USERPROFILE\Downloads;
.\FaceitEsportDiag.ps1

Lecture seule : rien n’est modifié. Admin = TPM / Secure Boot / NIC props plus complets. Un .txt s’ouvre sur le Bureau + Notepad.

02 — Compléter le ressenti

Le script ne peut pas “sentir” le jeu. Remplis ça, puis colle le rapport + ce bloc dans le chat.

03 — Envoyer

  • Complète la section MANUAL dans le .txt (ou utilise le bloc ci-dessus).
  • Colle tout le rapport dans le chat Cursor.
  • Diag priorisé ensuite : tearing vs frametime vs AC vs net — plan FACEIT-safe.
